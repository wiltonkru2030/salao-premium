# Identidade visual — SALÃO PREMIUM

Esta pasta reúne os arquivos oficiais da identidade visual usados no site e nos produtos da plataforma.

## Direção visual definida

- **Fundo principal:** branco (`#FFFFFF`).
- **Texto principal:** preto.
- **Ícones:** serão adicionados pelo responsável do projeto nesta pasta; priorizar versões consistentes e, quando possível, SVG.
- **Tipografia definida:** Body Grotesque Fit para títulos e Poppins Medium para textos e interface.
- **Estilo:** limpo, minimalista, premium e com boa legibilidade.

> Não alterar cores, fontes ou arquivos oficiais sem validar a identidade visual do projeto. Os códigos exatos das demais cores serão registrados quando a paleta final for confirmada.

## Organização dos arquivos

- `icones/` — ícones do site e do sistema (preferencialmente SVG; PNG quando necessário).
- `logos/` — logotipo principal, versões alternativas e símbolo isolado.
- `fontes/` — arquivos de fonte e respectivas licenças, quando houver autorização para armazená-los no repositório.
- `referencias/` — referências visuais e materiais de apoio.

## Como adicionar ícones

1. Envie os arquivos para a pasta `icones/`.
2. Use nomes curtos, minúsculos e separados por hífen, por exemplo: `calendar.svg`, `users.svg`, `settings.svg`.
3. Prefira SVG otimizado, com fundo transparente e sem cores fixas quando o ícone precisar herdar a cor definida pela interface.
4. Não envie arquivos de terceiros sem verificar a licença de uso.

## Observações

Esta pasta é a fonte central dos arquivos de marca. Quando a aplicação web for criada, os assets necessários serão integrados ao local de publicação da aplicação, sem duplicar versões desnecessariamente.
