# Cópia do Supabase do Salão Premium

Esta pasta registra o trabalho aplicado no projeto Supabase `salao-premium` (`vlifbvzlyzoncefvfgol`), conforme consultado em 20 de novembro de 2026.

- `migrations/` contém as 80 migrações registradas como aplicadas, com as versões e os nomes do histórico remoto.
- `functions/` contém o código das três Edge Functions implantadas.
- `manifest.json` registra os hashes SHA-256 dos arquivos, as versões das funções e a configuração de verificação de JWT.

Use esta pasta para consultar e comparar o histórico remoto. Os arquivos de trabalho ficam em `supabase/migrations/` e `supabase/functions/`. Algumas migrações registradas no Supabase têm conteúdo equivalente a arquivos versionados com outras datas ou nomes. Mesclar as duas listas para reaplicar as migrações pode duplicar alterações.

A cópia cobre código e migrações. Dados operacionais, contas de usuários, arquivos do Storage e segredos do projeto ficam no Supabase.
